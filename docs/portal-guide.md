# 合作方门户使用指南

招投标对外小门户（`/portal`）面向供应商等合作方：公开浏览招标公告、注册账号、报名、投标、查看中标结果。与内部系统账号体系完全隔离（独立 JWT，`aud=portal`，互不可调）。

## 门户地址与页面结构

| 页面 | 路径 | 登录要求 |
| --- | --- | --- |
| 招标公告列表（公开首页） | `/portal/tenders` | 免登录 |
| 公告详情 | `/portal/tenders/{id}` | 免登录（报名/投标需登录） |
| 注册 | `/portal/register` | 免登录 |
| 登录 | `/portal/login` | 免登录 |
| 我的参与（工作台） | `/portal/my` | 需门户登录 |

- 门户品牌跟随系统设置（系统管理 → 品牌设置的站点名称与 Logo）。
- 公告列表/详情显示报名/投标截止倒计时（≤3 天或已截止标红）；已定标项目公开中标单位与中标价。
- 工作台含：我的报名（含审核状态/意见）、我的投标（含报价）、中标结果（中标/未中标）。
- 支持中英文切换（页面右上角），移动端自适应。

## 合作方侧流程

1. 打开 `/portal` 浏览公告（无需账号）。
2. 注册：提交账号、密码（≥8 位）、公司名称、联系人/电话/邮箱。页面有审核流程说明。
3. 等待采购方审核；审核通过前不能登录（提示 96004）。
4. 登录后在公告详情页报名（可传资质附件），报名审核通过后投标（可传投标文件，截止前重复提交即改标）。
5. 定标后在公告详情/工作台查看中标公示。

## 管理侧：合作方账号操作

入口：**往来单位** 页面顶部切换到「合作方账号」视图（`/crm/customers?tab=accounts`）；或往来单位详情抽屉的「门户账号」tab（仅显示绑定到该单位的账号）。

| 操作 | 路径 | 说明 |
| --- | --- | --- |
| 审核（通过/拒绝/停用） | 账号视图行操作 / 抽屉 tab 行操作 | 通过时可绑定供应商往来单位（用于定标后生成采购合同） |
| 新建账号 | 账号视图「新建账号」按钮 | 直接启用、无需审核；可一并绑定往来单位 |
| 编辑资料/改绑/解绑 | 行操作「编辑」 | 绑定单位可改选；**清空即解绑**，解绑后不能投标，定标后也无法生成合同 |
| 重置密码 | 行操作「重置密码」 | 自动生成随机密码或指定（8-64 位）；新密码仅展示一次，请复制后告知合作方 |
| 删除 | 行操作「删除」 | 软删；已有报名/投标记录的账号不能删除（96007），只能停用 |

权限码：`procurement:partner:list/create/edit/review/delete`（挂在隐藏的 PartnerAccounts 菜单下，超管默认全量）。

抽屉「门户账号」tab 的空态会显示门户注册地址并可一键复制，便于发给合作方。

## 内外打通

- 内部招标详情抽屉有「对外公告链接」：发布后（published 及以后状态）显示 `http(s)://<host>/portal/tenders/{id}` 并可复制；草稿/已终止显示提示文案。
- 内部登录页有「合作方门户」入口；门户登录页有「内部员工入口」。
- 公告免登录口径：仅 published/evaluating/awarding/awarded 可见；匿名时 my* 字段为空，操作类端点（报名/投标/我的数据）仍需门户登录。
