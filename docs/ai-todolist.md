# AI 增强待办清单（bizSys）

> 基于当前系统现状（FastAPI + Vue3 + MySQL，模块：工作台/客户/合同/任务/报告/财务/审批/系统管理/企业微信集成）梳理的 AI 强化路线。
> 按优先级分三档：P0 = 低成本高收益速赢项；P1 = 中期核心增值；P2 = 长期智能化底座。
> 状态标记：`[ ]` 未开始 / `[~]` 进行中 / `[x]` 已完成。

---

## 0. 前置底座（所有 AI 功能的前提）

- [ ] **LLM 网关封装**（backend `integration` 模块下新增 `llm/`）
  - 统一封装 OpenAI 兼容协议客户端（DeepSeek / 通义 / Kimi / 私有化 vLLM 均可接），配置走现有 `sys_config`（系统设置里加"AI 设置"卡片：API Key、Base URL、模型名、开关）。
  - 带超时、重试、token 用量记账（写审计日志，便于成本核算）。
  - **安全红线**：合同金额、客户税号、财务数据属敏感信息，默认脱敏后出域；支持切换纯私有化模型（内网 vLLM/Ollama）以满足保密要求。
- [ ] **异步任务队列**：AI 调用耗时长，不能阻塞请求线程。轻量方案用 FastAPI BackgroundTasks + 数据库任务表即可；量大了再上 Celery/Redis。
- [ ] **AI 结果落库约定**：所有 AI 生成内容存草稿状态，必须人工确认后才转正（写审计日志 `ai_generated=true`），界面统一加"AI 生成"标识。

## P0 速赢（1~2 周/项，立即提升体验）

- [ ] **1. 智能表单填充与自动补全**（呼应会议记录"能做选择的就不应该让用户录入"）
  - 合同/任务新建时，输入名称关键词，AI 从历史数据推荐：客户、业务板块、承担部门、价格区间、付款周期。
  - 客户管理：输入客户名自动补全税号/开户行/地址（先精确匹配库内，再调 AI 联网或基于历史相似客户推测，推测值标黄需确认）。
- [ ] **2. 审批意见助手**（approval 模块）
  - 审批人打开待办时，AI 预生成审批意见草稿（同意/驳回两种措辞）+ 自动摘要审批单要点（金额、客户、历史审批链）。
  - 风险预检：金额超该客户历史均值、同一客户多合同并行未结算、合同周期异常等，AI 提示"建议关注"。
- [ ] **3. 企业微信 AI 日报/待办摘要**（integration 已有企业微信通道）
  - 每天早上给各角色推送个性化摘要：我的待办审批 N 条（附要点）、即将超期任务、本月到账/未结算金额。
  - 用现有定时机制（cron）+ LLM 把结构化数据转成人话。
- [ ] **4. 全局语义搜索**（顶栏 Ctrl+K 命令面板升级）
  - 现在的菜单搜索升级为全站搜索：合同号/客户名/任务名/报告标题模糊 + 语义检索（"上个月签的风洞合同"也能命中）。
  - 技术：MySQL 全文索引起步；后续 embedding 向量（可存 MySQL BLOB 或换 pgvector）。
- [ ] **5. AI 问答助手（只读）**
  - 侧边抽屉式助手，自然语言查数："本月开票多少""客户A还有几份合同没结算"。
  - 实现：LLM function-calling 映射到现有只读 API（绝不开放写接口），权限沿用当前登录人。

## P1 核心增值（贴合业务主流程：合同→任务→报告→财务）

- [ ] **6. 合同文件 AI 解析录入**
  - 上传合同 PDF/扫描件 → OCR + LLM 抽取：客户、金额、周期、付款方式、盖章类型 → 自动填新建合同表单，人工核对后提交。
  - 技术：OCR（PaddleOCR 私有化 或 云 OCR）+ LLM 结构化抽取（JSON schema 约束输出）。
- [ ] **7. 报告起草助手**（report 模块，会议记录明确提到"任务需要出报告、敲章"全流程）
  - 基于任务信息 + 样品信息 + 历史同类报告，AI 生成报告初稿（结论段、检测依据、数据描述套话）。
  - 报告英文版一键翻译（涉外客户场景）。
  - 盖章流程不变，AI 只出草稿。
- [ ] **8. 财务对账与开票助手**（finance 模块）
  - 发票 OCR：上传发票照片自动识别发票号/金额/税率，回填开票申请。
  - 到账智能匹配：到账登记时，AI 按金额+付款方+时间窗推荐最可能的合同/结算单，一键关联。
  - 月度财务异常扫描：长期已开票未到账、已结算未开票清单自动生成催办建议。
- [ ] **9. 任务智能排期**（task 模块 + 甘特图已有）
  - 新建任务时 AI 参考承担部门当前负载、历史同类型任务耗时，推荐计划完成日期与负责人。
  - 甘特图上标注预测延期风险（基于当前进度与剩余工作量）。
- [ ] **10. 会议纪要 → 任务自动创建**
  - 粘贴会议记录文本（如现有的 `会议记录总结.md` 类内容），AI 抽取行动项：任务名、负责人、截止日期 → 批量生成任务草稿待确认。

## P2 长期智能化底座

- [ ] **11. 数据质量巡检**
  - 定期扫描：客户资料缺联系人/税号、合同金额与任务总额不符、孤儿任务（无关联合同）等，生成修复建议清单进工作台。
- [ ] **12. 审计日志异常检测**（admin 审计模块）
  - 规则 + AI 双轨：非工作时间批量导出、频繁删除、权限异常变更自动告警（企业微信推管理员）。
- [ ] **13. 相似记录查重**
  - 新建客户/合同时 embedding 相似度检测，提示"疑似已存在：客户A / 客户A（改）"，防止脏数据。
- [ ] **14. 经营分析月报自动生成**
  - 每月初自动生成：签单额、到账额、任务完成率、客户排行、板块分布，LLM 写分析结论，推送给管理层。
- [ ] **15. 知识库问答**
  - 把制度文件、操作手册、历史报告（脱敏）灌入向量库，员工提问"XX 类型任务报告怎么写"直接给出处引用。

## 落地顺序建议

```
LLM 网关 + 系统设置 AI 卡片（底座）
   → P0-4 语义搜索 / P0-5 问答助手（只读、风险最低，先建立信任）
   → P0-2 审批助手 / P0-3 企微摘要（管理层感知最强）
   → P1-6 合同解析 / P1-7 报告起草 / P1-8 财务助手（业务主流程提效）
   → P2 巡检/查重/月报（数据积累够了再做）
```

原则：**AI 只出草稿和建议，人做最终确认**；所有 AI 操作留痕可审计；敏感数据默认不出内网。
